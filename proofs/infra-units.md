# infra-units — Units of imaginary quadratic orders (infrastructure)

## Statement

Throughout, $d \in \mathbb{Z}$ is a **negative discriminant**: $d < 0$ and $d \equiv 0$ or $1 \pmod 4$. We write

$$\mathcal{O}_d \;=\; \mathbb{Z}[\tau], \qquad \tau \;=\; \frac{d+\sqrt{d}}{2},$$

for the imaginary quadratic order of discriminant $d$; equivalently $\mathcal{O}_d \cong \mathbb{Z}[x]/(g)$ where

$$g(x) \;=\; x^2 - d\,x + \tfrac{d^2-d}{4}$$

is the minimal polynomial of $\tau$ (the constant term is an integer precisely because $d \equiv 0,1 \pmod 4$). As a $\mathbb{Z}$-module, $\mathcal{O}_d = \mathbb{Z} \oplus \mathbb{Z}\tau$. Writing $d = Df^2$ with $D$ the fundamental discriminant of $K = \mathbb{Q}(\sqrt d)$ and $f \geq 1$ the conductor, $\mathcal{O}_d$ is the unique order of index $f$ in the maximal order $\mathcal{O}_K = \mathcal{O}_D$; neither $D$ nor $f$ (nor the Chapter 3 quantity $w = v_p(f)$, see Remark 4) plays any role in this document beyond bookkeeping. The **norm** of $\alpha = x + y\tau$ ($x, y \in \mathbb{Z}$) is

$$N(x + y\tau) \;=\; x^2 + d\,xy + \tfrac{d^2-d}{4}\,y^2 \;\in\; \mathbb{Z}.$$

Denote by $\mathcal{O}_d^\times$ the group of units of the ring $\mathcal{O}_d$, and set $w(d) := \#\mathcal{O}_d^\times$.

> **Theorem (infra-units).** Let $d < 0$, $d \equiv 0, 1 \pmod 4$.
>
> 1. **(Generic case.)** If $d < -4$, then $\mathcal{O}_d^\times = \{1, -1\}$; in particular $w(d) = 2$.
> 2. **($d = -4$.)** $\mathcal{O}_{-4}^\times = \{\pm 1,\ \pm(2+\tau)\}$, a cyclic group of order $4$ generated by $2+\tau$ (which maps to $i$ under $\mathcal{O}_{-4} \cong \mathbb{Z}[i]$, $\tau \mapsto -2+i$); so $w(-4) = 4$.
> 3. **($d = -3$.)** $\mathcal{O}_{-3}^\times = \{\pm 1,\ \pm(1+\tau),\ \pm(2+\tau)\}$, a cyclic group of order $6$ generated by $-(1+\tau)$ (here $1+\tau \mapsto \zeta_3$, $2+\tau \mapsto \zeta_6$ under $\tau \mapsto \frac{-3+\sqrt{-3}}{2}$); so $w(-3) = 6$.
>
> Consequently $w(d) \in \{2, 4, 6\}$ for every negative discriminant $d$, with $w(d) = 4$ if and only if $d = -4$, and $w(d) = 6$ if and only if $d = -3$. Moreover every unit of $\mathcal{O}_d$ is a root of unity, so $w(d)$ equals the number of roots of unity in $\mathcal{O}_d$.

## Proof

### Preliminaries: conjugation and multiplicativity of the norm

Since $d < 0$ is not a perfect square, $g$ has no rational root and is irreducible over $\mathbb{Q}$; hence $\mathcal{O}_d$ is an integral domain of characteristic $0$, and $\{1, \tau\}$ is a $\mathbb{Z}$-basis, so an element $x + y\tau$ determines $(x,y)$ uniquely and $1 \neq -1$.

Set $\bar\tau := d - \tau$. Then $\bar\tau$ is the other root of $g$:
$$g(d - \tau) = (d-\tau)^2 - d(d-\tau) + \tfrac{d^2-d}{4} = \tau^2 - d\tau + \tfrac{d^2-d}{4} = g(\tau) = 0 .$$
By the universal property of $\mathbb{Z}[x]/(g)$ there is a unique ring homomorphism $\sigma : \mathcal{O}_d \to \mathcal{O}_d$ with $\sigma(\tau) = \bar\tau$, namely $\sigma(x + y\tau) = (x + dy) - y\tau$; since $\sigma(\bar\tau) = d - \bar\tau = \tau$, $\sigma$ is an involutive ring automorphism fixing $\mathbb{Z}$. Vieta for the monic $g$ gives
$$\tau + \bar\tau = d, \qquad \tau\bar\tau = \tfrac{d^2-d}{4},$$
whence for $\alpha = x + y\tau$,
$$\alpha\,\sigma(\alpha) = (x + y\tau)(x + y\bar\tau) = x^2 + xy(\tau + \bar\tau) + y^2\,\tau\bar\tau = \Big(x^2 + d\,xy + \tfrac{d^2-d}{4}\,y^2\Big)\cdot 1 = N(\alpha)\cdot 1 .$$
Identifying $\mathbb{Z}\cdot 1 \subseteq \mathcal{O}_d$ with $\mathbb{Z}$, we write $N(\alpha) = \alpha\,\sigma(\alpha)$. Because $\sigma$ is a ring homomorphism and $\mathcal{O}_d$ is commutative,
$$N(\alpha\beta) = \alpha\beta\,\sigma(\alpha)\sigma(\beta) = N(\alpha)\,N(\beta), \qquad N(1) = 1 .$$

### Lemma 1 (Completed square; positive definiteness)

*For every $x, y \in \mathbb{Z}$,*
$$4\,N(x + y\tau) \;=\; (2x + dy)^2 - d\,y^2 \;=\; (2x + dy)^2 + |d|\,y^2 ,$$
*the second equality because $d < 0$. Consequently $N(\alpha) \geq 0$ for all $\alpha \in \mathcal{O}_d$, and $N(\alpha) = 0$ if and only if $\alpha = 0$; in particular $N(\alpha) \geq 1$ for $\alpha \neq 0$.*

**Proof.** Since $d \equiv 0, 1 \pmod 4$, the integer $q := \frac{d^2-d}{4}$ satisfies $4q = d^2 - d$ exactly. Hence
$$4N(x+y\tau) = 4x^2 + 4d\,xy + (d^2 - d)y^2 = \big(4x^2 + 4d\,xy + d^2 y^2\big) - d\,y^2 = (2x+dy)^2 - d\,y^2 .$$
For $d < 0$ both summands $(2x+dy)^2$ and $|d| y^2$ are $\geq 0$, so $N \geq 0$. If $N(x+y\tau) = 0$ then $|d|\,y^2 = 0$ and $(2x+dy)^2 = 0$; since $|d| \geq 3 > 0$ the first forces $y = 0$, and then the second forces $x = 0$. $\square$

### Lemma 2 (Units have norm one)

*For $\alpha \in \mathcal{O}_d$: $\alpha \in \mathcal{O}_d^\times$ if and only if $N(\alpha) = 1$.*

**Proof.** ($\Rightarrow$) If $\alpha\beta = 1$ then $N(\alpha)N(\beta) = N(1) = 1$ by multiplicativity. Both factors are nonnegative integers (Lemma 1) whose product is $1$, so $N(\alpha) = 1$.

($\Leftarrow$) If $N(\alpha) = 1$ then $\alpha\,\sigma(\alpha) = 1$ with $\sigma(\alpha) \in \mathcal{O}_d$, so $\alpha$ is a unit with inverse $\sigma(\alpha)$. $\square$

### Proof of part 1 ($d < -4$)

Let $\alpha = x + y\tau$ be a unit. By Lemma 2 and Lemma 1,
$$(2x + dy)^2 + |d|\,y^2 \;=\; 4\,N(\alpha) \;=\; 4 .$$
If $y \neq 0$ then $|d|\,y^2 \geq |d| \geq 5$ (as $d < -4$ means $d \leq -5$, i.e. $|d| \geq 5$), which already exceeds $4$ — impossible since $(2x+dy)^2 \geq 0$. Hence $y = 0$, and the equation becomes $4x^2 = 4$, so $x = \pm 1$ and $\alpha = \pm 1$.

Conversely $N(\pm 1) = 1$, so $\pm 1$ are units, and $1 \neq -1$ since $\mathcal{O}_d$ has characteristic $0$. Thus $\mathcal{O}_d^\times = \{1, -1\}$ and $w(d) = 2$. $\blacksquare$

### Proof of part 2 ($d = -4$)

Here $q = \frac{16+4}{4} = 5$, $g(x) = x^2 + 4x + 5$, and $\tau^2 = -4\tau - 5$. Lemma 1 reads $4N = (2x-4y)^2 + 4y^2$, i.e.
$$N(x + y\tau) = (x - 2y)^2 + y^2 .$$
$N = 1$ forces $(x-2y, y) \in \{(\pm 1, 0), (0, \pm 1)\}$, i.e.
$$(x, y) \in \{(1,0),\ (-1,0),\ (2,1),\ (-2,-1)\} .$$
By Lemma 2 these four elements $\pm 1,\ \pm(2+\tau)$ are exactly the units. The group is cyclic of order $4$:
$$(2+\tau)^2 = 4 + 4\tau + \tau^2 = 4 + 4\tau + (-4\tau - 5) = -1 ,$$
so $2+\tau$ has multiplicative order $4$. Under the isomorphism $\mathcal{O}_{-4} \cong \mathbb{Z}[i]$ determined by $\sqrt{-4} = 2i$, i.e. $\tau = \frac{-4+2i}{2} = -2+i$, the generator is $2 + \tau = i$. Thus $w(-4) = 4$. $\blacksquare$

### Proof of part 3 ($d = -3$)

Here $q = \frac{9+3}{4} = 3$, $g(x) = x^2 + 3x + 3$, and $\tau^2 = -3\tau - 3$. Lemma 1 reads
$$(2x - 3y)^2 + 3y^2 = 4 .$$
The term $3y^2 \leq 4$ forces $y \in \{0, \pm 1\}$:

- $y = 0$: $4x^2 = 4$, so $x = \pm 1$;
- $y = 1$: $(2x-3)^2 = 1$, so $2x - 3 = \pm 1$, giving $x = 2$ or $x = 1$;
- $y = -1$: $(2x+3)^2 = 1$, so $2x + 3 = \pm 1$, giving $x = -1$ or $x = -2$.

By Lemma 2 the units are exactly the six elements $\pm 1,\ \pm(1+\tau),\ \pm(2+\tau)$, and $2 + \tau = 1 + (1+\tau)$, $-2-\tau = -(2+\tau)$. The group is cyclic of order $6$: with $\tau^2 = -3\tau-3$,
$$(1+\tau)^2 = 1 + 2\tau + \tau^2 = -2 - \tau = -(2+\tau), \qquad (1+\tau)^3 = (1+\tau)\cdot\big({-(2+\tau)}\big) = -(2 + 3\tau + \tau^2) = 1 ,$$
so $1+\tau$ has order $3$ and $-(1+\tau)$ has order $6$. Under $\tau = \frac{-3+\sqrt{-3}}{2}$ one has $1 + \tau = \frac{-1+\sqrt{-3}}{2} = \zeta_3$ and $2+\tau = \frac{1+\sqrt{-3}}{2} = \zeta_6$, so $\mathcal{O}_{-3}^\times = \mu_6$. Thus $w(-3) = 6$. $\blacksquare$

### Proof of the consequences

**Trichotomy.** The negative discriminants are $-3, -4, -7, -8, -11, -12, \dots$; the integers $-1, -2, -5, -6$ are excluded by the congruence ($-1 \equiv 3$, $-2 \equiv 2$, $-5 \equiv 3$, $-6 \equiv 2 \pmod 4$). Hence every negative discriminant other than $-3$ and $-4$ satisfies $d \leq -7 < -4$ and falls under part 1. Parts 1–3 then give: $w(d) = 2$ for $d < -4$, $w(-4) = 4$, $w(-3) = 6$; in particular $w(d) \in \{2,4,6\}$ always, $w(d) = 4$ iff $d = -4$, and $w(d) = 6$ iff $d = -3$.

**Units are roots of unity.** $\mathcal{O}_d^\times$ is a finite group of order $w(d)$, so by Lagrange every unit $u$ satisfies $u^{w(d)} = 1$. Hence the number of units equals the number of roots of unity in $\mathcal{O}_d$ (a root of unity is trivially a unit). $\square$

## Remarks

**Remark 1 (Divergence from the thesis: none to correct — the result is not proved there).** The thesis nowhere states or proves this theorem; it is *used* silently. §2.1 (p. 4) introduces "$w_i$ the number of roots of unity in $\mathcal{O}_{d_i}$" and asserts $w_2 = 6$ for $D_2 = -3$; §2.2 redefines $w_i = \#\mathcal{O}_{D_i}^\times$. The two definitions agree by the last consequence above (the unit group is finite, hence torsion). No item of ERRATA.md (E1–E7) touches this result: E1–E5 concern Theorem 3.1.2/Corollary 3.1.3, and E7's normalization questions ($8/(w_1w_2)$ vs $4/(w_1w_2)$) concern the *exponents* in Chapter 2 statements, not the values of $w$.

**Remark 2 (The congruence hypothesis is load-bearing in the Lean model).** The Lean definition `QuadraticOrder d` exists for *every* $d \in \mathbb{Z}$, with constant term $\lfloor (d^2-d)/4 \rfloor$ formed by integer division (divergence noted in `Basic.lean`). For $d \equiv 2, 3 \pmod 4$ the completed square of Lemma 1 acquires a defect: $4\lfloor(d^2-d)/4\rfloor = d^2 - d - 2$, so $4N = (2x+dy)^2 + (|d|-2)y^2$. The units statement is then **false without the congruence hypothesis**: `QuadraticOrder (-5)` is $\mathbb{Z}[x]/(x^2+5x+7)$, whose defining polynomial has discriminant $-3$ — it is the order $\mathcal{O}_{-3}$ in disguise, with **six** units (e.g. $N(2 + \tau) = 4 - 10 + 7 = 1$). Likewise `QuadraticOrder (-6)` is $\mathbb{Z}[x]/(x^2+6x+10)$ of discriminant $-4$, with four units, and `QuadraticOrder (-2)` is $\mathbb{Z}[x]/(x^2+2x+1) = \mathbb{Z}[x]/((x+1)^2)$, which is not even a domain. The Lean stubs must therefore carry the hypothesis $d \equiv 0, 1 \pmod 4$ alongside `d < -4` — as the existing stubs in `Units.lean` do (`hdisc : d % 4 = 0 ∨ d % 4 = 1`; recall `%` on `ℤ` is `Int.emod`, so the residues are nonnegative even for negative `d`).

**Remark 3 ("$d < -4$" vs "$d \leq -7$").** Under the congruence hypothesis the smallest discriminants below $-4$ are $-7$ and $-8$, so the hypotheses $d < -4$ and $d \leq -7$ cut out the same discriminants; but the proof of part 1 only needs $|d| \geq 5$, so the Lean statement should use the weaker, simpler `d < -4`.

**Remark 4 (Name collision: two different $w$'s).** Chapter 3 of the thesis uses $w := v_p(f)$ (the $p$-adic valuation of the conductor, as in Theorem 3.1.2), while Chapter 2 uses $w_i := \#\mathcal{O}_{d_i}^\times$. ERRATA E6.7 lists several such collisions ($R$, $\epsilon$, $s$) but not this one; it is the same hygiene class. In this document and its blueprint node, $w(d)$ *always* means the unit count; blueprint nodes for Chapter 3 should avoid the bare letter $w$ for the unit count (suggested: keep `w d` for units at the blueprint level and rename the valuation, or vice versa — to be fixed once at the blueprint level per PLAN §6.8).

**Remark 5 (Alternative proof not taken).** One could deduce part 1 from the classification of units of the *maximal* order ($\mathcal{O}_K^\times = \{\pm 1\}$ for $K$ imaginary quadratic, $K \neq \mathbb{Q}(i), \mathbb{Q}(\zeta_3)$) via $\mathcal{O}_d^\times \subseteq \mathcal{O}_K^\times$. We do not, for two reasons: the embedding $\mathcal{O}_d \hookrightarrow \mathcal{O}_K$ is not yet part of the Lean infrastructure (PLAN §4 item 1), and Mathlib's roots-of-unity/torsion theory for number fields (`NumberField.Units`) is maximal-order only (PLAN §4 item 7). The norm-form proof above is elementary and matches the already-formalized `normForm` API.

**Remark 6 (Finiteness for free).** Lemma 1 + Lemma 2 show $\mathcal{O}_d^\times$ is contained in the solution set of $(2x+dy)^2 + |d|y^2 = 4$, which is finite for every $d < 0$; so the unit group of *any* imaginary quadratic order is finite, without knowing $d$. Only the exact enumeration needs the case split on $d$.
